AgendaAlly — Storefront Discovery UI Consistency Pass

Implement a focused visual/design improvement across the existing Customer storefront discovery sections.

This is a UI/UX consistency pass based on the approved mockups.

Credit use is important.

Do NOT perform another broad application audit.
Do NOT redesign unrelated pages.
Do NOT change payment, booking, delivery, Maps, authentication, Vendor, Driver, invoice, financial, or backend business logic unless a tiny compatibility adjustment is strictly required for these existing discovery components.

The approved design direction is:

- clean, premium marketplace presentation;
- warm AgendaAlly neutral/bronze visual language;
- strong left alignment;
- consistent content width;
- consistent horizontal card rows;
- balanced whitespace;
- consistent cards across discovery sections;
- responsive mobile behavior;
- no giant empty horizontal areas;
- no randomly centered content;
- no uneven card heights caused by variable content.

Apply this system to:

1. Recommended businesses
2. Top specialists
3. Deals
4. New businesses
5. Product Brands / Browse product brands
6. All shops / Explore businesses

The existing APIs, filtering, visibility rules, navigation and authoritative data must remain intact.

==================================================
1. GLOBAL DISCOVERY LAYOUT
==================================================

First identify the shared Customer storefront container/grid primitives already used by these sections.

Do not independently hard-code six unrelated widths.

Use one coherent responsive content system.

Desktop:

- constrain content to the existing appropriate storefront max width;
- center the page container;
- LEFT-ALIGN section content inside it;
- section headings must start on the same left grid line;
- cards must start on that same left grid line;
- right-side controls must align with the right edge of the content container.

The desired structure is conceptually:

Section eyebrow / context where appropriate

Section title                         See all →   ‹  ›

[Card] [Card] [Card] [Card...]

NOT:

                 Section title

          [Card] [Card] [Card]

with large unused space around it.

Do not center Recommended, Specialists, Brands or Shops simply because only a few records exist.

Fewer records must remain LEFT-ALIGNED.

==================================================

flex-direction column
height 100%

metadata/content:
flex-grow 1

footer:

Use appropriate line clamps for descriptions.

Business names:

Descriptions:

Addresses:

Specialist specialty:

reserve a consistent metadata area.
