============================================================

Do not trust a PHP/ORM model hydrated before the lock wait.

Do not use:

- frontend serialization;
- process-local mutexes;
- arbitrary sleeps;
- timing assumptions;
- check-then-update outside one authoritative transaction;
- SQLite behavior as production proof.

If the existing schema can safely provide the serialization boundary, use it.

No schema migration is authorized by this brief.

If a schema change is actually required, STOP BEFORE MIGRATION and explain why.
