3. CURRENT KNOWN EVIDENCE
============================================================

The accepted prior review established from public MTN documentation:

- RequestToPay is asynchronous.
- Server-owned request identity must be persisted before provider submission.
- Status lookup uses the original request reference.
- 202 is not proof of payment.
- Callback delivery is not sufficient by itself and polling/reconciliation is
  required.
- The reviewed public sandbox documentation specifies target `sandbox` and
  currency EUR.

The prior review DID NOT establish that:

- Cameroon/XAF is unsupported;
- Cameroon/XAF is supported under the public EUR sandbox;
- EUR should replace XAF;
- FX should be introduced;
- the public sandbox represents the actual Cameroon merchant environment.

Preserve that distinction.
