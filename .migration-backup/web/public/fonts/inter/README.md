# Bundled Inter font

`InterVariable.woff2` is the original Inter typeface used by this storefront,
bundled locally so development and production builds do not contact Google
Fonts. It supports the original variable weights and Latin/Cyrillic text.

Source: https://github.com/rsms/inter/tree/master/docs/font-files
