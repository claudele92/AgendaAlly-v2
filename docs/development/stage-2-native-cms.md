# Native Stage 2 editorial and support

The maintained Next.js Blog/list/detail, About, FAQ, Contact, Terms and Privacy
pages use their existing Laravel CMS contracts and content. Blog pagination is
locale-aware, dates are formatted intentionally, author labels require actual
API fields, and existing comments/reviews remain available.

FAQ answers are keyboard-operable native disclosures with readable CMS HTML.
Loading, API error, empty and pagination-retry states are distinguished.
Legal samples retain the prominent non-operative owner/legal-review notice;
no new policy promises were written into the database.

Unverified support contacts and seeded download/social placeholders are not
presented as official destinations. There is no fake contact submission flow.
Final native browser evidence is recorded in the integration report.
